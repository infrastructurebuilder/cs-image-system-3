# Contract: the quickstart page's format

**Feature**: [spec.md](../spec.md) | **Decisions**:
[research.md](../research.md) R3, R6, R11, R13, R16

What `scripts/quickstart` reads from `docs/QUICKSTART.md`. Anything not
listed here is prose for the reader and is not read by any program.

## Boxes

- A **box** is a fenced block whose info string is exactly `sh`. Every
  box on the page is run, in page order. A block shown only to be read
  uses `text`.
- A box's first line is its header comment, `# step N -- box M of K --
  vN`, as every walk in this repository has.
- A **command** is a line of a box that is neither blank nor a comment,
  after a trailing `\` has joined it with the next line.
- The line whose output the reader checks is the last line of its box.
  A box expected to take more than 30 seconds says how long in a comment
  line under its header.
- There are ten or fewer commands on the page in all.

## The commands, as planned

```text
# step 1 -- box 1 of 3 -- v1
# About a minute on a fresh machine: uv fetches the packages and, if needed, Python 3.13
uv tool install --upgrade --index-url https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ \
  --index-strategy unsafe-first-match 'cs-image-system[docker]==<version>'
uv tool install --upgrade 'ansible-core>=2.16'
export PATH="$(uv tool dir --bin):$PATH"
cs-image-system --version

# step 2 -- box 2 of 3 -- v1
cs-image-system init-config csis-quickstart --from standard-docker
cs-image-system --root-dir csis-quickstart validate

# step 3 -- box 3 of 3 -- v1
# One to three minutes the first time: the vendor image, the packer plugins, the OpenTofu provider
cs-image-system --root-dir csis-quickstart run --all
```

Seven commands, the version line included (the first is one command
over two lines). `<version>` stands here for the release the page names,
written in it as a number and moved by each release's bump (research
R4); the page itself never shows a placeholder. Until 1.0 the install
takes every name of the system from TestPyPI and every other from PyPI
(specification 013). The last line of box 1 prints the release; of box 2, `Validation successful.`; of box 3, `Run
<id> completed: identity, storage, base-image, instance-image, release,
retention`.

## The prerequisites table

Between these two comments, and nowhere else on the page:

```text
<!-- prerequisites: generated by scripts/quickstart prerequisites --write; do not edit -->
| Tool | At least | Where it comes from |
| --- | --- | --- |
| ... one row per prerequisite ... |
<!-- end of prerequisites -->
```

"Where it comes from" links to the daily driver's section 1.2, the one
place that says where every tool comes from.

## The ending

The page ends with a section of three links, one per line: a first real
local run (the docker starter's README, "A first real run"), the cloud
starters (the `standard-aws` README), and a team's own repository (the
daily driver, section 1.9). No program reads them; the quickstart walk
checks each link's first command (story 4).
