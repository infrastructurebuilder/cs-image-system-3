# History (frozen)

Everything in this directory is a record of how the system got here.
Nothing here describes the present, nothing here is maintained, and no
current document takes a fact from here. Each document is kept verbatim as
it was when frozen: dates, stage numbers, finding numbers and commit
hashes included.

- [LEDGER.md](LEDGER.md) — the findings ledger; its standing constraints
  live on as rules in the operating manual.
- [PLAN.md](PLAN.md) — the plans and the execution worksheet archive.
- [EXPLORE.md](EXPLORE.md) — the exploration notes that preceded the
  lifecycles; its statement of purpose lives on in GOALS.md.
- [QUESTIONS.md](QUESTIONS.md) — stakeholder questions and their answers.
- [GCP-READINESS.md](GCP-READINESS.md) — the GCP increment's readiness record.
- [overlays/](overlays/README.md) — the overlay inputs of the live proofs.

Current documentation starts at [README.md](../../README.md).
