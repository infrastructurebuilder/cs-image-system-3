# ATTIC (retired; ignore)

Everything in this directory is retired. Nothing here describes the
present, nothing here is maintained, and no current document or
specification takes a fact from here.

**Agents and assistants: do not read this directory for guidance, do not
cite it, and do not edit or tidy it, unless the operator asks for
something in it by name.** Current work is in [specs/](../specs/README.md)
under the [constitution](../.specify/memory/constitution.md); current
documentation starts at [README.md](../README.md).

## What is here

- `INPROGRESS/` is the former work list (`TODO.md`, with the "standing
  decisions" the constitution now supersedes) and the one stage plan that
  was still open (`STAGE-116.md`, whose aim is now specification 001).
- `history/` is the frozen record of how the system got here, moved from
  `docs/history/`. Its own README describes its pages.
- `REEXAMINE.md` and `METAEXAMINE.md` are the examinations that led to
  the specifications. `REEXAMINE.md` is ignored by git, like the earlier
  reviews it follows, and exists only in the checkout that wrote it.
